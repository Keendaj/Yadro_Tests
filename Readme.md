# MediaScanner API

## Требования
- Компилятор с поддержкой **C++17**
- **CMake** (версия 3.14 или выше).
- **Make** (или Ninja).
- POSIX-совместимая операционная система (Linux / WSL) для поддержки `pthreads`.

## Инструкция по сборке

Проект собирается с помощью системы CMake. Откройте терминал в корневой папке проекта и выполните следующие команды:

```bash
mkdir build
cd build
cmake ..
make
